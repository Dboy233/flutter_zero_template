> 本目录存放 `{{name}}` 功能模块的 **data 层网络数据模型**。

This directory holds the **data-layer network models** for the `{{name}}` feature module.

---

## 中文说明

- 本文件夹内的文件用于定义 `{{name}}` 模块从服务端接口接收/发送的网络数据模型（DTO / Entity）。
- 模型通常由 `freezed` + `json_serializable` 生成（`*.freezed.dart`、`*.g.dart` 为自动生成产物，请勿手动修改）。
- 这些模型仅服务于 `{{name}}` 模块自身的数据层；跨模块共享的模型不应放在此处（应上移至公共层或对应归属模块）。
- 网络异常与字段校验逻辑不在模型中处理，交由 Repository 与 BLoC 业务层决定。

## English

- Files in this folder define the **network data models (DTO / Entity)** that the `{{name}}` module sends to and receives from backend APIs.
- Models are usually generated by `freezed` + `json_serializable` (`*.freezed.dart`, `*.g.dart` are generated artifacts — do not edit them manually).
- These models serve only the `{{name}}` module's own data layer. Models shared across modules should not live here (promote them to the common layer or the owning module).
- Network errors and field validation are **not** handled inside the models; they are left to the Repository and BLoC business layer.

---

## 约定 / Conventions

- 命名：以业务语义命名（如 `post_model.dart`）。
- 生成产物：`.freezed.dart` / `.g.dart` 自动生成，提交但勿手改。
- 单一职责：每个模型文件聚焦一类网络数据结构。
