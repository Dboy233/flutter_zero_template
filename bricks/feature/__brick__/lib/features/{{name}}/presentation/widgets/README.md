# widgets（小组件目录）

本目录存放 `{{name}}` 功能内**可复用的纯展示组件**（无状态 / 轻状态 UI 部件）。

## 职责

- 组合基础 Widget，封装本功能常见的视觉片段：列表项、卡片、输入框、空状态、加载骨架等。
- 仅负责渲染与交互回调（通过构造参数传入 `onTap` 等）；不持有 BLoC、不发起网络请求、不含业务判断。

## 存放内容

- 本功能专用的展示组件：`xxx_card.dart`、`xxx_list_item.dart`、`xxx_skeleton.dart` 等。
- 与功能强相关、但不宜直接平铺在 `pages/` 的局部 UI。

## 约定

- 不要把所有 UI 都堆在 `pages/`：可复用的片段抽到这里，由 `pages/{{name}}_body.dart` 组合调用。
- 全局通用组件（按钮、对话框、加载框等）应放在 `core/ui` 或更高层；**本目录只放功能私有组件**。
- 组件保持小而专注、可独立测试；需要 BLoC 状态的复杂部件谨慎放入（优先在页面层用 `BlocBuilder` 包裹）。
- 本功能的状态/事件在 `bloc/`、副作用处理在 `effects/`、页面在 `pages/`：请勿与这些目录的职责混淆。
